## What is FeedMe?

FeedMe is a web-based food ordering platform built as a CP3407 project. Our brief was to design and develop a better version of FoodPanda — one that is faster, cleaner, and easier to use for customers, restaurant owners, delivery riders, and administrators.

The platform allows customers to browse restaurants near them, view menus, place orders, and track delivery in real time. Restaurant owners can manage menus and monitor incoming orders. An admin panel provides full oversight of all platform activity.

## Technology Stack Summary

| Layer | Technology | Why We Chose It |
|-------|-----------|-----------------|
| Frontend | HTML, CSS, JavaScript | Lightweight, no framework overhead, fast load times |
| Backend | PHP | Server-side rendering, easy MySQL integration |
| Database | MySQL | Relational data model suits our order/user/restaurant structure |
| Containerisation | Docker | Consistent dev environment across all team members |
| Hosting | AWS Lightsail | Affordable, scalable cloud hosting for deployment |
| Version Control | Git & GitHub | Industry-standard collaborative development |
