# Building and Development Tools

This page documents the software development tools, cloud services, and external libraries utilized to build, deploy, and manage the FeedMe platform.

---

## 1. Cloud Infrastructure & Hosting
To meet the high-standard project requirements, we utilized **Amazon Web Services (AWS)** for our production environment.

* **AWS EC2 :** Used as our primary web server to host the PHP backend and WordPress frontend.
  
---

## 2. Development Stack & Building Tools
We selected a modern tech stack that prioritizes speed and scalability.

* **Version Control (GitHub/Git):** Used for collaborative development, branching, and maintaining a clean commit history. This repository serves as our primary project output.
* **Backend:** PHP was used for server-side logic and database connectivity, allowing for rapid customization of the FeedMe system.
* **Database:** A relational **MySQL** database was implemented to manage complex data for users, menus, and orders.
* **Frontend:** Built using HTML5, CSS3, and JavaScript to provide a modern, responsive Graphical User Interface (GUI).
