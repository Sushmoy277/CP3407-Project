# Pages and Features 

## Overview
This section defines the customer-facing pages and features of the FeedMe system.



## Home Page
Features:
- Display platform introduction
- Search for restaurants or meals
- Show featured restaurants
- Display offers and promotions
- Navigation to login and register



## Register Page
Features:
- User registration form
- Input fields for name, email, password, phone number, and address



## Login Page
Features:
- Secure login system
- Redirect to homepage/dashboard after login



## Restaurant Listing Page
Features:
- Browse all restaurants
- Search by name
- Filter by category and food type (halal, vegetarian, vegan, spicy)
- View ratings and delivery time



## Restaurant Details / Menu Page
Features:
- View restaurant information
- Display menu items with images and prices
- Add items to cart
- View ratings and reviews



## Cart Page
Features:
- View selected items
- Update item quantity
- Remove items
- View total price



## Checkout Page
Features:
- Confirm delivery address
- Select payment method
- Place order



## Order Tracking Page
Features:
- View order status
- Track delivery progress
- Display estimated delivery time



## Order History Page
Features:
- View previous orders
- Reorder items
- View order details



## Review Page
Features:
- Rate restaurants
- Submit reviews and feedback
