

## Overview

FeedMe follows an Agile development approach using Scrum methodology. This allows the team to develop the system in iterations, deliver features gradually, and improve based on feedback.



## Agile Methodology (Scrum)

The project is divided into small iterations called sprints.

Each sprint includes:
- Planning
- Development
- Testing
- Review

This approach helps ensure the system is delivered on time and meets user requirements.



## Why Agile is Used

- Allows flexibility in development
- Helps handle changes easily
- Supports continuous improvement
- Ensures regular progress tracking



## Team Roles

### Scrum Master
- Manages the development process
- Ensures tasks are completed on time
- Removes blockers

### Developers
- Build frontend and backend features
- Work on database and APIs
- Implement user stories

### Product Owner (Team Representative)
- Defines requirements
- Prioritises user stories
- Ensures project meets goals



## Justification

Agile is chosen because:
- It matches the iterative nature of software development
- It allows continuous delivery of features
- It improves team collaboration



## Sprint Structure

The project is divided into multiple sprints.

Each sprint duration:
- 1–2 weeks

---

## Sprint 1 (Initial Setup)

Tasks:
- Setup GitHub repository
- Define user stories
- Define system features
- Plan architecture
- Assign team roles

---

## Sprint 2 (Core Development)

Tasks:
- Build frontend pages (home, login, register)
- Setup backend server
- Create database structure
- Implement user authentication

---

## Sprint 3 (Main Features)

Tasks:
- Restaurant listing and menu system
- Cart and checkout system
- Order placement functionality
- Order tracking system

---

## Sprint 4 (Advanced Features)

Tasks:
- Admin dashboard
- Restaurant dashboard
- Rider delivery system
- Reviews and ratings

---

## Sprint 5 (Testing & Deployment)

Tasks:
- System testing
- Bug fixing
- Deploy system on AWS
- Final improvements

---

## Task Breakdown

Each user story is divided into smaller tasks to make development easier.

Example:
User Story: Place Order  
Tasks:
- Create cart system
- Build checkout page
- Integrate payment system
- Save order in database

---

## Justification

Sprint planning helps:
- Manage workload efficiently
- Track progress
- Deliver features step by step
