## Overview

The FeedMe system is designed with a focus on simplicity, usability, and accessibility. The goal is to create an intuitive interface similar to FoodPanda but improved for better user experience.

-[Interface Design](https://www.figma.com/board/7PcOZ8ORDOZHcP3hYhWP62/CP3407-Project?node-id=0-1&t=TFO8SAobrxVPzwNE-0)


## Design Principles

- Simple and clean interface
- Easy navigation across pages
- Consistent layout and design
- Responsive design for all devices
- Fast interaction and minimal loading time



## Layout Design

The system follows a consistent layout:

- Header: logo, search bar, navigation menu
- Main content: dynamic page content
- Footer: links, contact information



## Navigation Design

Navigation includes:
- Home
- Restaurants
- Cart
- Orders
- Login/Register

This allows users to easily move between sections without confusion.



## Justification

These design choices ensure:
- Better usability
- Faster user interaction
- Reduced complexity
- Improved user satisfaction

## User Flow

### Customer Flow

1. User visits homepage
2. Searches or browses restaurants
3. Selects a restaurant
4. Adds items to cart
5. Proceeds to checkout
6. Places order
7. Tracks delivery



## Restaurant Flow

1. Restaurant logs in
2. Views incoming orders
3. Accepts and prepares order
4. Updates order status



## Rider Flow

1. Rider logs in
2. Receives delivery task
3. Picks up order
4. Delivers order
5. Marks as completed



## UX Considerations

- Fast navigation between pages
- Minimal steps to place an order
- Clear feedback (order status, confirmations)
- Error handling (invalid inputs, failed actions)



## Accessibility

- Readable fonts
- Clear buttons and icons
- Mobile-friendly design
- Simple interaction flow


## Justification

The UX design ensures:
- Users can complete tasks quickly
- The system is easy to learn
- The experience is smooth and efficient
