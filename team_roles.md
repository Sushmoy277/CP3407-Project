# Team Roles – FeedMe Project

## Overview

The FeedMe project is developed by a team of three members. Each member is assigned specific responsibilities to ensure efficient development and proper task distribution.



## Team Members and Roles

### Sushmoy Paul Rohit – Frontend Developer

Responsibilities:
- Design and develop user interface (UI)
- Implement pages such as home, restaurant, cart, and checkout
- Ensure responsive and user-friendly design
- Work on UI/UX improvements



### Ornysha Biswas – Backend Developer

Responsibilities:
- Develop server-side logic using Node.js and Express
- Handle user authentication and API development
- Manage communication between frontend and database
- Implement business logic (orders, payments, tracking)



### Mohammad Ramiz Karim – Database & System Manager

Responsibilities:
- Design and manage database structure (MySQL)
- Handle data storage and retrieval
- Ensure data consistency and security
- Assist with testing and system integration



## Collaboration Approach

- GitHub is used for version control and collaboration
- Each member works on separate parts and commits regularly
- Tasks are managed using Agile methodology
- Regular communication is maintained to track progress



## Justification

This role distribution ensures:
- Clear responsibility for each team member
- Efficient development process
- Balanced workload
- Better project organisation

It also supports Agile development by allowing parallel work on different system components.
